# Orient — two ceremonies, one grammar

Before you run anything: what this repo demonstrates, and the one idea that ties
it together.

**Everything on the fabric is a principal under a unit.** A human operator, a
headless sensor, a UAS — each is an identity minted across the planes it needs,
stamped with the same five-dimension grammar (role · affiliation · echelon ·
node-class · site), and traceable to whoever brought it online. Onboarding is the
ceremony that mints that identity. Humans and machines run **sibling** ceremonies
— same grammar, same registry, different gates — not two disconnected systems.

Run: `bin/hg-onboard 00-orient`
